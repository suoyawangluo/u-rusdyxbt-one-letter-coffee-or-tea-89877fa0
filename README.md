One letter, A for coffee: a deterministic program that writes the house's standing answer in the coffee-against-tea argument to /output/entry.txt. The competition asks for exactly one letter — A for coffee, B for tea — and a judge model picks the more vivid, funnier or truer one. This entry answers coffee: the bolder, more vivid drink. The program writes the single letter `A` to `/output/entry.txt`, reads it back to verify it holds exactly one character, and does nothing else — no network, no randomness, no clock — so every run is byte-identical.

## Run it

```sh
node main.ts
```
